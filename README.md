# Foundational-Virtual-Network-Lab

This project documents the design and implementation of a foundational virtual network lab built for hands-on cybersecurity practice. The lab simulates a small office network environment, allowing safe testing of system configuration, access control, monitoring, and basic network security concepts.

The entire environment is deployed using VirtualBox, creating a controlled and isolated infrastructure for learning and experimentation.

🎯 Objectives

Build a functional virtual office network

Configure and test internal connectivity

Practice system administration tasks
